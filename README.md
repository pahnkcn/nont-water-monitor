# ระดับน้ำท่าน้ำนนท์

เว็บอ่านระดับน้ำจากไม้วัดระดับน้ำในกล้อง CCTV ท่าน้ำนนท์ (https://cctv-nont.firsttech.co.th/) ทุก 10 นาที
แสดงผลบนหน้าเว็บ และส่ง Web Push เข้ามือถือของคนที่กดเปิดการแจ้งเตือน

- ข่าวระดับน้ำตามรอบ: ทุก 1, 3, 6 ชั่วโมง หรือวันละครั้งตามเวลาที่เลือก มีช่วงไม่รบกวน
- เตือนทันทีเมื่อถึงระดับเฝ้าระวังหรืออันตราย เตือนซ้ำเมื่อสูงขึ้นอีก 10 ซม. และแจ้งเมื่อน้ำลด
- กราฟย้อนหลัง 24 ชม. / 7 วัน / 30 วัน, ภาพล่าสุดพร้อมเส้นผิวน้ำที่ระบบอ่านได้, ภาพสด, บันทึกการเตือน
- หน้า `/admin` สำหรับตั้งเกณฑ์และตำแหน่งไม้วัดโดยไม่ต้อง deploy ใหม่

ทุกอย่างรันบนบริการฟรี: Vercel Hobby, Upstash Redis (free) และ cron-job.org

## ทำงานอย่างไร

1. ตัวตั้งเวลาภายนอกเรียก `GET /api/cron/tick` ทุก 10 นาที
2. ฟังก์ชันใช้ ffmpeg ดึง 3 เฟรมจาก segment ล่าสุดของสตรีม HLS
3. `lib/gauge.ts` ไล่หาจุดที่หน้าไม้วัดสีขาวหายไปใต้ผิวน้ำ แล้วแปลงตำแหน่งเป็นเมตรด้วยจุดเทียบใน `lib/gauge-config.ts`
4. `lib/alerts.ts` ตัดสินสถานะ ปกติ / เฝ้าระวัง / อันตราย (มีระยะกันแจ้งไปมา)
5. ส่ง push ให้เครื่องที่ถึงรอบหรือที่ต้องได้เตือน เครื่องที่ยกเลิกไปแล้วถูกลบอัตโนมัติ

## Deploy บน Vercel (ฟรี)

1. **อัปโหลดโค้ดขึ้น GitHub** (repo ส่วนตัวหรือสาธารณะก็ได้)
2. **Vercel** → Add New Project → เลือก repo → Deploy (ค่าเริ่มต้นใช้ได้เลย)
3. **ฐานข้อมูล**: ในโปรเจกต์ Vercel → Storage → Marketplace → **Upstash Redis** → แผน Free → Connect กับโปรเจกต์นี้
   (Vercel ใส่ `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้เอง)
4. **Environment Variables** (Settings → Environment Variables) ใส่ค่าจากไฟล์ `.env.local` ในเครื่อง:

   | ชื่อ | ค่า |
   | --- | --- |
   | `VAPID_PUBLIC_KEY` | กุญแจสาธารณะสำหรับ push |
   | `VAPID_PRIVATE_KEY` | กุญแจลับสำหรับ push (ห้ามเผยแพร่) |
   | `VAPID_SUBJECT` | URL เว็บของคุณ เช่น `https://ชื่อโปรเจกต์.vercel.app` |
   | `CRON_SECRET` | รหัสสุ่มยาว ใช้ยืนยันตัวตนตัวตั้งเวลา |
   | `ADMIN_PASSWORD` | รหัสเข้าหน้า `/admin` |

   ถ้ายังไม่มีกุญแจ สร้างใหม่ได้ด้วย `npx web-push generate-vapid-keys`
   เปลี่ยนกุญแจภายหลังแล้วเครื่องที่สมัครไว้ต้องกดเปิดการแจ้งเตือนใหม่
5. กด **Redeploy** ให้ค่า env มีผล
6. **ตัวตั้งเวลาทุก 10 นาที** (Vercel ฟรีให้ cron วันละครั้งเท่านั้น):
   - สมัคร https://cron-job.org (ฟรี) → Create cronjob
   - URL: `https://ชื่อโปรเจกต์.vercel.app/api/cron/tick`
   - Schedule: ทุก 10 นาที
   - Advanced → Headers → เพิ่ม `Authorization` = `Bearer <ค่า CRON_SECRET>`
   - Timeout: 30 วินาทีขึ้นไป
   - `vercel.json` มี cron วันละครั้งไว้เป็นตาข่ายสำรองอีกชั้น
7. เปิด `https://ชื่อโปรเจกต์.vercel.app/admin` → ใส่รหัส → กด **อ่านค่าตอนนี้** ต้องได้ตัวเลขระดับน้ำ
8. ตั้ง **เกณฑ์เฝ้าระวัง / อันตราย** ที่หน้า `/admin` (ค่าเริ่มต้น 2.20 / 2.50 ม. เป็นค่าชั่วคราว)
   และตรวจว่าเลขหลักเมตรบนไม้วัดตรงกับภาพ ถ้าไม่ตรงกดเลื่อนสเกล ±1 ม.

### ทางเลือกแทน cron-job.org

GitHub Actions เรียก endpoint เดียวกันได้ (`schedule: cron: "*/10 * * * *"` + `curl -H "Authorization: Bearer ${{ secrets.CRON_SECRET }}"`)
แต่รอบของ GitHub มักช้ากว่ากำหนด 5 ถึง 15 นาที

## iPhone / iPad

iOS ส่ง Web Push ได้เฉพาะเว็บที่เพิ่มลงหน้าจอโฮมแล้ว (iOS 16.4 ขึ้นไป): Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม → เปิดจากไอคอน → กดเปิดการแจ้งเตือน
หน้าเว็บแสดงขั้นตอนนี้ให้เองเมื่อเปิดจาก Safari บน iPhone

## พัฒนาในเครื่อง

```bash
npm install
npm run dev      # ไม่มีค่า Upstash ก็รันได้ ข้อมูลเก็บในหน่วยความจำ
npm test         # ทดสอบตัวอ่านไม้วัดกับภาพจริง, state machine การเตือน, ตารางเวลา
```

เรียกอ่านค่าหนึ่งรอบในเครื่อง:

```bash
curl -H "Authorization: Bearer $CRON_SECRET" http://localhost:3000/api/cron/tick
```

เก็บภาพจากกล้องไว้ตรวจตัวอ่าน: `scripts/capture-fixture.sh`

## งบใช้งานฟรี (โดยประมาณ)

- Vercel Active CPU: ffmpeg ราว 0.3 ถึง 1 วินาทีต่อรอบ × 4,320 รอบต่อเดือน อยู่ในโควตาฟรี 4 ชม.
- Upstash: ราว 10 คำสั่งต่อรอบ ≈ 45,000 คำสั่งต่อเดือน (ฟรี 500,000)
- Vercel Hobby ใช้ได้กับโปรเจกต์ไม่แสวงหากำไร

## ข้อจำกัด

- ค่าเป็นค่าประมาณจากภาพ ไม่ใช่ข้อมูลทางการ ไม่ทราบระดับอ้างอิงของไม้วัด
- หน้าเว็บและการแจ้งเตือนไม่แสดงเป็นเมตร แสดงเป็นระยะห่างจากเกณฑ์ (ซม.) ค่าเมตรตามสเกลไม้วัดมีแค่ในหน้า `/admin`
- เลขหลักเมตรที่รอยต่อไม้วัดอ่านจากภาพไม่ชัด ตั้งไว้ว่าแผ่นล่าง 1.xx / แผ่นบน 2.xx
- ถ้ากล้องถูกขยับ ต้องแก้ตำแหน่งไม้วัดใน `/admin`
- ไอคอนแอปใน `public/icons/` เป็นแบบชั่วคราว วาดจาก `scripts/make-icons.mjs` เปลี่ยนเป็นโลโก้จริงได้

ภาพจากกล้อง CCTV ของเทศบาลนครนนทบุรี สนับสนุนโดยบริษัท เฟิร์สเทค ดีไซน์ จำกัด โปรเจกต์นี้ทำขึ้นอิสระ ไม่ได้เป็นของหน่วยงานทั้งสอง
